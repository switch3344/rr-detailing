# Диагностика до правок — 2026-11-08

Исходный коммит a7ad967. Тексты/шрифты/структура не меняются. Снимки: artifacts/before, эксперимент с crease: artifacts/experiments/creased.png. Все камеры воспроизводятся через npm run car:shots, dev /debug/car.

Не подтверждено: остаток разбора в hero. Каждый FileModel клонирует исходную сцену, разбор меняет только собственный клон; rest-эксперимент не исправляет крыло/порог. Отдельно будет проверено 20 сборок с точным сравнением матриц.

Не подтверждено: orange peel на краске. У основных окрашенных Material.042/.049 normalMap отсутствует, а normalScale [1,1] не оказывает эффекта без карты. Отключение всех normal-карт не исправляет волны. blank_normal и flat_nm — служебные карты, будут удалены из использования.

Цветовые пространства: baseColor — sRGB, normal — linear; anisotropy 8, mipmaps включены. Некоторые исходные цветовые карты содержат освещение/AO, их нельзя считать полноценным PBR-набором.

Геометрия: desktop 345433 треугольника, mobile 110041. 42 треугольника имеют нормаль, противоположную усреднённой нормали вершин; 11126 близки к нулевой площади (включая мелкие игровые элементы, не доказательство дыр кузова). Точных дублей mesh+transform не найдено. polygonOffset выключен, у непрозрачных материалов depthWrite включён. Большинство швов уже есть в геометрии; рисовать фиктивные швы поверх неправильных панелей нельзя.

Предварительный вердикт: материалы/стекло/свет исправимы. Простое усреднение нормалей не подходит. Если после контролируемого weighted-normal эксперимента останутся локальные заломы крыла и порога, нужна замена ассета; затемнение не является исправлением.
