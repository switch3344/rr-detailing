# Итог проверки

Тексты, шрифты, секции и услуги сохранены. Диагноз — reports/01-diagnosis.md, ограничения ассета и инструкция замены — reports/02-asset-gate.md. Машина остаётся исходной пользовательской GT3 RS, двигатель — Lamborghini V12.

Изменено: нормали Blender с сохранением позиций/UV, явные роли через manifest, графитовая краска с clearcoat, прозрачное стекло без молочной заливки, тёмная алькантара/швы с корректной alpha-mask, графитовые диски, карбон, контрастный студийный свет, затухающий отражающий пол, почти чёрная палитра. Новых внешних шрифтов/фото/HDRI нет.

Прелоадер: реальная загрузка ArrayBuffer в общий Three Cache, затем декодирование и три отрисованных кадра; шрифты — document.fonts. Прогресс монотонный, без таймера, имитирующего загрузку. Окружение процедурное, внешнего HDRI-запроса нет. Минимум 700 мс, таймаут 12 с, шторка 800 мс/reduced-motion fade. При таймауте процент не становится фиктивными 100%. Файлы следующих сцен подгружаются за 1.6 экрана, создание Canvas отделено от предзагрузки, чтобы не мешать hero. Локальные Draco/Basis, embedded WebP, без CDN.

Размеры: desktop GLB 6.329 → 6.889 MB; mobile 3.545 → 3.795 MB. Критичный пакет до первого кадра около 8.7 MB по несжатым размерам файлов, около 7.7 MB с gzip JS/CSS (не VRAM). Все 8 GLB валидны: 0 ошибок, 0 предупреждений. Треугольники: desktop 345433 → 345376, mobile 110041 → 110035; удалились вырожденные треугольники при повторном Draco. Количество/названия групп сохранены.

20 полных циклов разбора/сборки: точное совпадение TRS всех узлов, следовательно совпадают локальные матрицы. Прогоны 30 раз вверх-вниз на 1280/1920/390, CPU ×4: результаты в verification.json и artifacts/verification/results.json. Проверяются четыре постоянных контекста, отсутствие потерь/пропаданий, неизменность выбранной вкладки и отсутствие повторных GET для моделей.

Production Fast 3G (1.6 Мбит/с, latency 150 мс): открытие около 12.1 с, реальный прогресс 32%, затем силуэт и продолжение загрузки. Сбой сети и некорректный GLB: страница открывается примерно за 0.75–0.86 с, доступен повтор. Лог процента и времени: artifacts/verification/production.json. Это запрошенный лог вместо GIF.

Обычный запуск на тестовом хосте: первый смысловой кадр/начало шторки около 6.6 с, повторный заход около 1.44 с, mobile viewport около 3.73 с. Headless-замеры нельзя выдавать за замеры физического телефона. Цель 55 FPS на холодной сцене не достигнута; после прогрева частота значительно выше. Полные цифры и условия в verification.json. Первичная компиляция shader-программ остаётся заметной.

Lighthouse до/после: JSON и HTML в artifacts/verification/lighthouse-*.report.*. Raw LCP учитывает текст прелоадера и не равен первому кадру машины; поэтому условие «не хуже +0.5 с по смысловому кадру» не подтверждено. Снижение Performance не скрывается усреднением или выбором лучшего запуска. CLS после изменения остаётся малым; окончательные значения — в verification.json.

## Не закрытые пункты

Нужна замена ассета: локальные заломы крыла/порога и грубые элементы исходника всё ещё видны на светлом кузове. Не добавлены фиктивные панели или швы, не использовано затемнение для маскировки. Полноэкранные SSAO/bloom не включены; бюджет отдан устойчивости четырёх контекстов. Геометрия линз/рефлекторов не восстановлена. Коммерческая лицензия текущего исходника не подтверждена. Требования и контракт замены зафиксированы в manifest и отчёте гейта.

## Воспроизведение

npm ci; npm run build; npm run car:shots. Dev /debug/car: normals, wireframe, solo, боксы групп, таблица и 7 фиксированных камер. npm run car:shots создаёт desktop/mobile «до/после» через RR_PHASE. scripts/site-qa.mjs управляет собственным dev-сервером. Production QA/Lighthouse используют preview; для Lighthouse отдельно установить npm install --prefix .qa-tools lighthouse. Технические зависимости не включены в клиентский bundle.
