# RR Studio

Сайт детейлинг-студии: Porsche 992 GT3 RS, разбор кузова и демонстрационного Lamborghini V12. Диски, тормоза, шины и насадки выпуска взяты из модели GT3 RS. Переключение тюнинга выполняется кнопками. На мобильных устройствах загружаются облегчённые модели.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
node scripts/check-car.mjs
```

Сборка находится в dist. Все модели, шрифты и декодеры обслуживаются с того же сайта. Относительные пути поддерживают GitHub Pages в подпапке репозитория.

## Публикация

Сайт: https://switch3344.github.io/rr-detailing/
Исходники: ветка main. Опубликованная сборка: ветка gh-pages.

Контакты студии пока не заполнены; скрытые ссылки можно включить через src/content.ts после получения данных.
Источники моделей и шрифтов перечислены в CREDITS.md. Исходные ZIP и рабочие Blender-файлы остаются локально и не входят в репозиторий публикации.

## Текущая ревизия 3D

Рабочая копия опубликованной версии находится здесь: Y:/Сайты/rr-detailing/.rr-studio-pages. Родительская папка содержит другой незавершённый проект; его исходники не заменялись.

Параметры: src/three/car.config.ts и src/three/scene.config.ts. Контракт замены GLB: src/three/car.manifest.json и reports/02-asset-gate.md.

```sh
npm run car:shots
node scripts/site-qa.mjs
```

Inspector /debug/car работает только в dev. QA-снимки/логи лежат в artifacts, технические отчёты — в reports. Прелоадер ждёт только hero и его декодирование/первый кадр, среду и шрифты; остальные сцены начинают загрузку после открытия, за 1.6 экрана до появления. Таймаут 12 с, минимум 700 мс, reduced motion — fade. При сбое доступен силуэт и явная повторная загрузка.
